# GhostPrint
## Gcode Post-processor for Disabling Heaters, Fans, and Motors

- Knocks out heater/fan Gcode commands
- Selectively "disables" motors during a print

**Note: works ONLY on ``.gcode`` files sliced with a *lightly* modified slicer profile, will not work on ``.bgcode``**.
